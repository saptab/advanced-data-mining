## Project Deliverables

Students are expected to complete an open-source codebase and deliver either theoretical results backed by simulations or a concrete application solution. The final project should combine technical rigor with a defensible implementation and clear evaluation.

### Final Components

- Open-source documented code
- An 8-page single-column report in LaTeX
- Presentation slides with visualizations
- Final presentation of the project

### Expectations

The course is outcome-driven and research-focused. Students should use the semester to develop a workable, well-documented project that connects core data-mining methods with agentic AI, scientific discovery, or decision-making systems.

More details will be provided as the course progresses.
